LazyDog Editor is now live on the Microsoft Store

LD LazyDog Team  ·  09 Sep 2026
LazyDogTemplates  |  LazyDog Studios
← Back to Journal
Platform · Windows Price · Free download Status · Live now

A few weeks ago we told you the LazyDog Editor was becoming a proper Windows application. That work is done: the LazyDog Editor is live on the Microsoft Store today, free to download, free to use.

Get it fromMicrosoft Store

What you get

Same editor you already know from the browser — a full ribbon (Home, Insert, Draw, Design, Transitions, Animations, Slide Show, Review, View), Templates, Elements, Photos, Backgrounds, Layers, Brand and Projects down the side — now running as its own Windows application instead of a browser tab.

Your files stay yours

Open a deck straight from your Documents folder and save it back — no upload step.

It stops fighting your browser

No tab crashes, no shared memory with a hundred other pages.

Editing stays free

Typing, moving, resizing, exporting — free, always. Only the AI automation runs on paid tokens.

If you never touch the AI tools, the desktop editor costs you nothing, forever. Pricing for the automated tools is explained in full on the pricing page.

Also new: a Tools section
The editor now has a permanent home alongside every other app LazyDog Studios builds. Read about it in the previous post.
